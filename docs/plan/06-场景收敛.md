## 第一版固定演示菜单

### 主菜（必做，3 个）

1. **能耗抄表 / 紫涵雅集**
   - 流程：拍 6 个表 → AI 自动 OCR 读数 → 一屏看到全部数字 → 一键确认 → 提交
   - 卖点：原本人工抄 6 个数字 + 拍 6 张图 + 在企微表单填 6 次，现在拍完直接出数字
   - 数据：图清晰，AI 准确率应该 >95%

2. **强电井 / 紫涵雅集综合巡检 - 室内情况**
   - 流程：拍除湿机屏 → AI 读"湿度 34% / 温度 21℃" → 自动判定"正常"（阈值湿度<70 & 温度<40） → 显示 → 确认 → 提交
   - 卖点：AI 看屏幕 → 直接给"正常 / 异常"结论 + 数值证据
   - 数据：屏幕大、字大，AI 必中

3. **热水机房 / 控制柜显示温度**
   - 流程：拍控制柜 → AI 读"60℃" → 显示 → 确认 → 提交
   - 卖点：单字段秒填
   - 数据：金锴 Keader 控制柜屏，显示稳定

### 辅菜（剧本变化用，2 个）

4. **消防泵房 / 一拍纸质巡视表自动填整张数字表（差异化亮点）**
   - 流程：拍墙上挂的纸质巡检表 → AI OCR 表格结构 + 手写内容 → 自动填充数字表的「水位 / 污水泵 / 漏水报警 / 卫生 / 照明 / 巡查人」6 个字段 → 人工核对 → 提交
   - 卖点：**这个最容易让评委记住** — 因为它解决了"为什么纸质表和数字表要填两遍"的真痛点
   - 风险：手写体识别准确率比印刷体低，需要 prompt 里特别处理
   - 优先级：v1 能进就进，进不了就砍到 v1.5

5. **故意失败重拍剧本（任意场景，建议用强电井）**
   - 流程：拍模糊照 / 拍墙 / 拍鞋 → AI 识别失败 → 弹窗"无法识别，请重新拍摄" → 重拍 → 第 3 次后跳手动填写页
   - 卖点：演示降级闭环（评委一定会问"AI 错了怎么办"）
   - 实施：用上面任一场景的 ground truth 图作为"成功路径"，故意拍坏照作为"失败路径"

### 砍掉的（明确不做）

- ❌ 扶梯巡检（没图）
- ❌ 电梯巡检（无机房）（没图）
- ❌ 电梯巡检（有机房）（图大、AI 价值低、字段多为人工功能测试）
- ❌ UPS 机房（环境照为主，AI 识别价值低）
- ❌ 变电所（柜阵列照，屏幕 OCR 难度大）
- ❌ 生活水泵 / 消防泵环境照（"绿色地坪 + 红色泵"那类纯环境照）

> **代码层处理**：这些表的 schema 仍保留在系统里（数据库表已建），只是前端不显示入口、demo 不演示。后续真要补很容易。
