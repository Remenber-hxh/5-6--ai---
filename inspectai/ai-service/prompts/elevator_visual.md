# 电梯视觉巡检

> 适用模板：`elevator_no_room`、`elevator_machine_room`、`escalator`
> 输入图片：电梯轿厢内部、操作面板、层门/轿门、消防开关、机房或扶梯相关部位
> 任务定位：视觉合规检查，不做设备维修结论，不默认现场正常

## 任务

请只根据照片中**清晰可见**的内容识别巡检字段，并返回 JSON。

必须遵守：
- 不要假设设备一定正常。
- 不要因为模板里有字段就强行填值。
- 看不清、没拍到、角度不足时，不返回该字段，让系统进入人工复核。
- 只有照片能明确支持时，才填写“正常 / 完好 / 异常 / 破损 / 缺失”等值。
- 如发现关键照片缺失，可以在 `nonconformity` 中写明需要补拍的部位，但不要把缺失照片直接等同于设备异常。

## 字段映射

| code | label | 输出要求 |
| --- | --- | --- |
| `inspection_time` | 检查时间 | 不从照片识别，由系统注入，不返回 |
| `asset_no` | 电梯编号 | 只有能清楚读到完整编号时返回 |
| `inspector` | 检查人员 | 由系统注入，不返回 |
| `door_running` | 层门/轿门运行 | 能看到门体对齐、无明显破损时可返回“正常”；明显错位、脱落、破损时返回“异常” |
| `buttons_display` | 按钮与显示 | 能看到按钮/显示屏状态时再返回；黑屏、缺失、烧毁、明显异常时返回“异常” |
| `lighting` | 轿厢照明 | 能看到轿厢照明状态时再返回；明显无光或灯具脱落时返回“异常” |
| `fire_switch_glass` | 消防开关玻璃 | 能看到玻璃完整时返回“完好”；明显裂纹返回“破损”；确认缺失才返回“缺失” |
| `nonconformity` | 不符合项处理情况记录 | 仅在发现异常或关键照片缺失时填写简短说明 |

## 输出格式

只返回 JSON，不要额外解释。`recognized` 里只放有视觉依据的字段。

```json
{
  "recognized": [
    {
      "code": "buttons_display",
      "value": "正常",
      "confidence": 0.88,
      "reason": "照片中可见按钮面板和显示屏，未见黑屏、缺失或烧毁"
    }
  ]
}
```

## 置信度规则

- 0.90-0.98：照片清晰、字段证据充分。
- 0.75-0.89：可判断但存在轻微角度、光线或遮挡影响，需要人工快速复核。
- 低于 0.75：不要返回该字段。
