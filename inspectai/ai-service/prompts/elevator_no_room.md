# 无机房电梯巡检（视觉合规检查）

> 适用模板：`elevator_no_room`（电梯巡检（无机房））
> 输入图片：1-6 张，常见为：机房/设备间门与警示标识、设备区（盘车手轮·松闸扳手·救援说明牌、控制柜、照明与空调温控器、灭火器）、轿厢操作面板（楼层按钮/显示、警铃、消防返回开关）、轿厢与候梯厅照明、特种设备使用标志/登记证、灭火器合格证与压力表。
> 任务定位：视觉合规检查，只把照片里**能确认的事实**变成字段，不做维修结论，不默认现场正常。

## 总则
- 选项字段全部是 `["是","否"]`：**是 = 符合要求 / 完好 / 正常 / 齐全**；**否 = 不符合 / 缺失 / 破损 / 异常 / 过期**。
- **直接可见项要主动判断,不要为"求稳"留空**：清洁度、操作面板/楼层按钮与显示、照明、各类标识/登记证/灭火器/救援装置是否在位完好——只要相关画面拍清楚,就给出"是/否";其中状态明显正常/完好的就大胆判"是"（少量灰尘、零星碎屑、脚印、反光不算异常）。
- 只有**功能性、声音、气味、速度**等照片本身判不了的项（如装置是否"有效"、开关门是否顺滑、有无异响）才留空交人工——这类没有可见证据时不返回。
- 真的看不清、没拍到、角度不够的项才不返回，不要用"否"代替"没拍到"。
- 关键照片缺失可在 `nonconformity` 写"建议补拍 XX"，但缺照片 ≠ 设备异常。

## 字段映射
| code | label | 判断依据（看到什么才给值） |
| --- | --- | --- |
| `inspection_time` | 检查时间 | 系统注入，不返回 |
| `asset_no` | 电梯编号 | 仅当编号牌/《特种设备使用标志》单位内编号**清晰可读**时返回 |
| `inspector` | 检查人员 | 系统注入，不返回 |
| `door_window_sign` | 机房门窗、警示标识完好 | 门窗完好关闭、危险/禁止入内/禁止攀爬等警示标识齐全完好 → 是；缺失/破损 → 否 |
| `room_clean` | 机房干净无杂物 | **拍到机房/设备间/地面就判断**：地面基本整洁、无明显杂物堆放/积水/油污 → 「是」（少量灰尘、零星碎屑、脚印、反光不算异常，不要因此判否）；明显堆放杂物/积水/漏油/脏乱 → 否 |
| `lighting_ac` | 机房照明及空调正常 | 照明明亮且空调/温控器在运行（亮屏显示温度、制冷标志，室温约 18-27℃）→ 是；无照明/空调黑屏不工作/温度明显异常 → 否 |
| `extinguisher_valid` | 灭火器材未过期 | 压力表指针在**绿区** 且 合格证/检查记录卡有效期未过 → 是；指针红区/已过期/记录长期空缺 → 否；只拍到瓶体看不到压力表与日期 → 不返回 |
| `noise_smell` | 设备无异响、异味 | 照片不能感知声音气味；仅当**看见**漏油、线缆烧焦、部件松脱等可见异常才返回"否"，否则不返回 |
| `rescue_device` | 紧急救援装置齐全 | 盘车手轮、松闸扳手、救援说明牌齐备就位 → 是；明显缺失 → 否；未拍到该区域 → 不返回 |
| `reg_mark` | 电梯使用登记标志完好 | 《特种设备使用标志》/登记证在位、完好、可读 → 是；缺失/破损/已过下次检验日期 → 否 |
| `alarm_device` | 紧急报警装置有效 | 操作盘上警铃按钮在位完好（可见标识/亮灯）→ 是；缺失/明显损坏 → 否；"是否有效"需实测、无可见依据 → 不返回 |
| `anti_clip` | 轿门防夹人装置有效 | 能看见光幕/防夹触板在位完好 → 是；缺失/损坏 → 否；功能是否有效无法从照片判定 → 不返回 |
| `door_smooth` | 开关门运行无卡阻 | 属功能性项，照片通常无法判定 → 不返回；仅当可见门体卡滞、错位、脱轨 → 否 |
| `floor_buttons` | 选层按钮及显示正常 | **拍到轿厢操作面板就判断**：楼层按钮（如 B1/1/M/2/3/4）排列齐全、无缺失/烧毁，楼层指示灯或显示点亮正常 → 「是」（高可视项，看到完好面板即可判，不必另要角度）；明显黑屏/按钮缺失/破损/烧灼 → 否 |
| `car_lighting` | 候梯厅、轿厢内照明正常 | 轿厢及候梯厅照明明亮 → 是；明显无光/灯具脱落 → 否 |
| `fire_switch_glass` | 消防开关玻璃完好 | 消防返回开关玻璃完整 → 是；明显裂纹/破损 → 否；确认缺失 → 否 |
| `nonconformity` | 不符合项处理情况记录 | 仅在发现异常或关键部位未拍到时填简短说明（<40字） |

## 输出
严格遵循 `_common.md` 的 JSON schema：`recognitionStatus` / `observations`（按图顺序）/ `recognizedFields`（只放有视觉依据的字段，code 必须完全等于上表，choice 值只能是 `"是"`/`"否"`）/ `warnings`。

## 置信度
- 0.90-0.98：标识/装置/压力表清晰、证据充分。
- 0.70-0.89：可判断但有反光、角度或轻微遮挡，需人工快速复核。
- 低于 0.70：不返回该字段。
