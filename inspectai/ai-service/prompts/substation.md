# 变电所巡检场景 — 手写巡检表 OCR + 设备照片辅助

> 适用模板：`power_room`（变电所巡检）
> 输入图片：通常 2-4 张，包含 ①手写巡检记录表（核心数据源）②高压柜/低压配电柜 ③变压器/机房环境
> 核心认知：变电所的电压/电流/温度数据**来自手写巡检表**，不是设备屏幕。设备照片只用于辅助确认外观/照明/卫生。

## 任务

变电所巡检以**手写巡检记录表**为主要数据源：OCR 读出表上当次时段（最早一列已填写的）的三相电压、变压器三相温度、各外观勾选项；设备照片用于辅助确认机房照明、卫生、柜体/变压器外观。

## ⚠️ 强制人工填写字段 —— AI 一律不返回

以下 7 个字段图片无法可靠判断，**绝对不要**出现在 `recognizedFields` 里，必须留空给巡检员现场人工填写：

| code | label | 为什么强制人工 |
| --- | --- | --- |
| `asset_no` | 变电所编号 | 柜体铭牌易糊、易拍错柜，错号后果严重 |
| `transformer_noise` | 变压器声音是否异常 | 图片物理上无法判断声音 |
| `hv_alarm` | 高压柜是否有报警 | 柜面红灯多为运行指示灯，AI 极易误判 |
| `meter_abnormal` | 高压柜电度表是否显示异常 | 需现场逐表核对，远景读不准 |
| `temperature_humidity_abnormal` | 高压柜温湿度是否异常 | 无温湿度数据源 |
| `hv_smell` | 高压柜有无异常气味 | 图片物理上无法识别气味 |
| `room_temperature_humidity` | 机房温湿度 | 巡检表上无此项，无数据源 |

→ 这 7 个 code 一律不填、不猜。`warnings` 里统一提示一次"上述字段按规则留人工填写"。

## ✅ AI 识别字段 —— 从手写表为主、照片为辅

### 从手写巡检表 OCR
| code | label | 怎么读 | 阈值/判定 |
| --- | --- | --- | --- |
| `inspection_time` | 日期+时间 | 表头日期 + 已填那一列的时间（如 9:00） | 输出 `YYYY-MM-DD HH:MM` |
| `voltage_normal` | 高压柜电压是否正常 | 读 1# 进线柜三相电压（AB/BC/AC 相，单位 V） | 三相都在 342~418V（380V±10%）→「是」；任一超出 →「否」 |
| `transformer_temperature` | 变压器温度及三相温差 | 读变压器 A/B/C 三相温度（℃） | 填 `A48 B51 C49℃，温差3℃`，温差=max−min |
| `hv_appearance` | 高压柜外观是否良好 | 表上「开关柜、变压器外观是否完好」勾选 | ✓→「是」 ✗→「否」 |
| `transformer_appearance` | 变压器外观是否良好 | 同上「外观完好」勾选 | ✓→「是」 |
| `room_lighting` | 机房照明是否正常 | 表上「照明是否正常」勾选 | ✓→「是」 |
| `room_clean` | 机房卫生 | 表上「室内设施是否良好」勾选 | ✓→「正常」 |

### 从设备照片辅助（手写表读不到对应项时才补，置信度更低）
- 机房照明：照片灯具亮 → `room_lighting`「是」
- 机房卫生：地面整洁、绝缘垫铺设、无杂物 → `room_clean`「正常」
- 柜体/变压器外观：柜门无变形、无破损、无漏油漏液 → 对应 appearance「是」

## 怎么读手写表

- 表格有多个时间列（9:00 / 13:00 / 18:00 / 21:00 / 0:00 / 6:00），**只读最早一列已填写的那一栏**（当次巡检），其余空列忽略
- 手写数字 OCR 易混：`4/9`、`0/6`、`1/7`、`5/3`。三相电压正常在 380~420V 区间，若读出明显离谱值（如 40 或 4000）→ confidence 降到 0.6 并在 warnings 提示可能误读
- 勾选符号：`✓ / √ / 对勾`→「是」/「正常」；`✗ / × / 叉 / 横线`→「否」/「异常」；空白→不填该字段
- 若 2# 进线柜 / 2# 变压器那几行全是 0 → 表示该路未投运/备用，**不报异常**，但在 `observations` 注明"2#路未运行"

## 阈值判定细则

电压 `voltage_normal`：
```
三相电压(AB/BC/AC)全部 ∈ [342, 418]V（380V ±10%） → "是"
任一相 < 342 或 > 418 → "否"，reason 注明是哪一相、多少 V
三相任一读不出 → 不填该字段（留人工）
```

变压器温度 `transformer_temperature`：
```
直接填三相实测值 + 温差，格式 "A48 B51 C49℃，三相温差3℃"
参考：正常运行 < 85℃、三相温差宜 < 15℃；超出在 reason 里提示，但值照填
```

## 失败 / 降级判定

- 只拍了设备照片、没拍手写巡检表 → 电压/温度等数值类一律不填，仅填照片可判的外观/照明/卫生，warnings："未拍到巡检记录表，电压/变压器温度需人工补填"
- 手写表拍糊 / 反光 / 字迹读不清 → 对应数值字段不填、confidence 低，warnings 提示重拍那张表
- 当次时间列整列空白（还没抄录就来拍）→ `recognitionStatus: "retake_required"`，retakeReason="巡检表本次时段未填写，请先现场抄录数据再拍照"

## 不要做

- **不要**给这 7 个字段填值：`asset_no`、`transformer_noise`、`hv_alarm`、`meter_abnormal`、`temperature_humidity_abnormal`、`hv_smell`、`room_temperature_humidity`（强制人工）
- 不要把手写表里 2#（全 0 那路）当异常
- 不要看到柜面红灯就判 `hv_alarm` 异常
- 不要把电流值（A）误填到电压字段（V）
- 不要把时间戳填进任何业务字段
