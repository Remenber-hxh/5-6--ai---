# 能耗抄表场景 — 紫菡雅集

> 适用模板：`zihan_energy`
> 输入图片：1-6 张，分别对应 Z1/Z2/Z3/Z4 能耗表 + 生活水表 + 消防水表
> 关键挑战：电表 LCD 屏可能显示多个量纲（EP 有功、EQ 无功、Ia 电流、Ub 电压等），只取 EP 主读数

## 任务

从用户上传的电表 / 水表 LCD 屏照片里读出**累计读数**，填到对应字段。

## 字段映射约定

字段清单里出现的 code → 现场对应：

| code | 现场设备 | 单位 | 屏幕标识 |
| --- | --- | --- | --- |
| `z1_reading` | Z1 能耗表（电表） | kWh | LCD 屏顶部显示 "EP" 或 "ΣEP" |
| `z2_reading` | Z2 能耗表（电表） | kWh | 同上 |
| `z3_reading` | Z3 能耗表（电表） | kWh | 同上 |
| `z4_reading` | Z4 能耗表（电表） | kWh | 同上 |
| `living_water_reading` | 生活水表 | m³ | 机械字轮表，黑色整数位 + 红色小数位（小数位忽略） |
| `fire_water_reading` | 消防水表 | m³ | 机械字轮表，黑色整数位 + 红色小数位（小数位忽略） |

## 高优先级：先判断表型，再读数字

每张图片必须先判断表型，再按对应规则读取。不要直接把图中最大/最清晰的数字当读数。

表型分类：

1. `lcd_energy_meter`：蓝底或液晶屏电表，常见标识 EP / ΣEP / kWh / Wh，数字可能分上下两行。
2. `mechanical_water_meter`：机械字轮水表，黑底白字或白底黑字窗口，旁边可能有红色小指针盘。
3. `unknown_meter`：无法确认表型或关键读数被遮挡。

输出 reason 必须说明表型，例如：

```text
图1为机械水表，黑色字轮显示000722，去前导0后读作722
图2为YKE蓝屏电表，EP读数分上下两行显示，必须按屏幕真实小数点位置读数；看不清小数点时留空并提示人工复核
```

## 怎么从照片判断是哪个表

用户**不会标注**这是 Z1 还是 Z2。你按以下顺序判断：

1. **看用户上传顺序**：第 1 张通常是 Z1，第 2 张 Z2，依此类推；生活水表、消防水表通常在电表之后。但顺序不绝对可靠。
2. **看现场标牌**：电柜上常贴 "Z1 / Z2 / Z3 / Z4" 标识或 "1#变压器 / 2#变压器" 字样。
3. **看显示器型号 + 颜色 + 摆位区分**：能耗电表通常是数字 LCD（蓝底显示）；水表是机械字轮（白底黑数字红色小数）。
4. **拿不准就按上传顺序**，但 reason 里说明"按上传顺序假设"，confidence 降到 0.7。

## 电表读数怎么读

### 规则 1：只读 EP / ΣEP 主电量

- 屏幕上的 `EP` / `ΣEP` 是正向有功电能标识，通常对应要填的 kWh 读数。
- 如果当前帧显示 `EQ`、`Ia`、`Ub`、`Uab`、电流、电压、无功等非 EP 数据，不要填能耗读数；在 warnings 里提示等屏切到 EP 后重拍。
- 不要读取 `DO1`、`DI1`、`Wh`、`varh`、按钮文字、型号、时间、报警灯旁边文字。

### 规则 2：上下两行数字不是小数点

LCD 电表经常把同一个读数分成上下两行显示。**禁止把换行位置当作小数点**。

错误示例：

```text
上排：1505
下排：2777
错误输出：1505.2777
```

### 规则 3：YKE 蓝屏电表必须识别真实小数点位置

YKE 蓝屏电表的 EP 主读数可能显示为上下两行。**小数位长度不是固定的**，不能统一按末两位、末三位或换行位置处理。

正确做法：

1. 先确认屏幕标识是 `EP`。
2. 读取上排数字和下排数字。
3. 重点观察下排数字附近是否有很小的小数点、数字间距、右侧 `k` 前的小数结构。
4. 按屏幕真实小数点位置输出；看不到小数点时，降低 confidence 并提示人工复核。
5. 不要把上下两行之间的换行当作小数点。

示例：

```text
EP
1505
2777k
```

如果能清楚看到真实小数点，再输出对应读数；如果看不到小数点，不要自行决定小数位。

注意：下排如果以 `0` 开头，这个 `0` 必须保留参与读取；不要因为屏幕右侧有 `k` 就把下排整体当小数。

### 规则 4：如果屏幕有真实小数点，才按真实小数点读

如果 LCD 上能清楚看到真实小数点，直接按屏幕上的真实小数点输出。
如果没有看到真实小数点，confidence 不得高于 0.65，并提示人工复核，不要自行决定小数位。

## 水表读数怎么读

生活水表和消防水表都按机械字轮水表处理，只取黑色字轮窗口中的主读数。

关键规则：

1. 黑色字轮窗口里的数字全部是整数位，包括最后一位黑色数字。
2. 不要把最后一位黑色数字当成小数。
3. 红色字轮、红色指针小盘才可能是小数位；当前日报不需要小数，直接忽略。
4. 前导 0 可以去掉。
5. 表盖编号、二维码、`Q1/Q2/Q3`、百分比、检验编号、厂家编号不是读数，必须忽略。

示例：

```text
黑色字轮：000722
输出：722
```

因此这种水表**必须输出 `722`，不能输出 `72.2`**。

再例：

```text
黑色字轮：[0][0][1][2][8][6]，旁边红色小盘或红色小数为5
输出：1286
```

红色小数位忽略，输出整数 m³。

## 反错误校验

在输出 recognizedFields 前必须自检：

- 如果机械水表输出值带小数点，确认小数点是否来自红色小数盘；如果只是来自黑色字轮最后一位，必须改为整数。
- 如果 LCD 电表输出值看起来像把“上排数字.下排数字”直接拼接出来，说明可能把换行误当小数点；必须降低置信度、提示人工复核，不要自行改成猜测值。
- 如果读数来自设备编号、二维码、Q1/Q2/Q3、百分比、型号标签，必须删除该字段，不要输出。
- 如果无法确认表型或小数位规则，confidence 不得高于 0.65，并在 warnings 里提示人工复核。

## 不要把这些当读数

- LCD 屏右下角的"通讯"指示灯
- 屏的时间戳（"04/29 15:13"）
- 红色报警灯（出现 → 在 warnings 里提示"该表显示报警"，但仍可读数）
- 别的表的反光投影
- 水表表盖上的 25649966 等设备编号
- 水表标签里的 Q1 / Q2 / Q3 和百分比
- 二维码旁边的编码、厂家名、检验章
- 电表上的 YKE、TX、MENU、Wh、varh、DI/DO 状态文字

## 失败判定

特定到本场景的失败条件：

- 屏被反光完全遮挡 → retake_required，reason="电表屏幕反光严重，请避开光源重拍"
- 屏显示的是 EQ/Ia 等非 EP 数据 → retake_required，reason="屏幕未显示 EP 主读数，请等屏切到 EP 后重拍"
- 拍到了表但显示器熄屏 → retake_required，reason="电表显示器未亮，请按表面任意键唤醒后重拍"
- 5 张图全部读不出 → retake_required

部分图能读：照常返回 recognized，能读的塞进 recognizedFields，读不出的留空。

## 关键约束 — 只读图里实际能看到的

**严禁凭空生成读数**。这是高优先级规则：

1. **N 张图就最多返回 N 个数值**。如果用户只上传 1 张图，最多 1 个 recognizedFields 项。
2. **图里看不到的字段 → 不出现在 recognizedFields 里**。不要根据"清单里有 5 个表"就编 5 个数字。
3. 所有 value 必须能在 observations 里找到对应的"图 N 显示 ..."依据。无依据的 value 视为编造。
4. 如果一张图上只看到一个表，无法判断是 Z1/Z2/Z3/Z4 哪个，按 reason 字段说明"按上传顺序假设是 Zn，confidence 降到 0.7"，且只填一个字段。

**违反任一条会被视作识别失败**。

## 输出示例

下面例子里**所有数字都用 ⟨示意⟩ 占位**，提醒你不要照抄数值。
真实输出时，每个 value 必须是你从图片里实际读出的数字。

```json
{
  "recognitionStatus": "recognized",
  "retakeReason": "",
  "observations": [
    "图1：机械水表黑色字轮显示000722，去前导0后为722",
    "图2：YKE蓝屏电表显示EP，上排与下排数字清晰，小数点位置按屏幕真实显示确认"
  ],
  "recognizedFields": [
    {"code": "living_water_reading", "value": "722", "confidence": 0.92, "reason": "图1机械水表黑色字轮为000722"},
    {"code": "z1_reading", "value": "1234.5", "confidence": 0.90, "reason": "图2 EP读数小数点清晰可见"}
  ],
  "warnings": [
    "若现场确认图2不是Z1，请人工调整到对应表字段"
  ]
}
```

**再次强调**：value 字段填实际从图里读到的数字，不是占位符 ⟨...⟩。如果你不确定哪个字段，**宁可不填**也不要填占位符或猜测值。

## 不要做

- 不要把单位（kWh / m³）写进 value
- 不要把屏幕上的时间戳填到任何字段
- 不要因为某张图读不出就整体 retake_required，部分识别也算 recognized
- 不要给小数水表数（机械水表的红色小数位精度不够，扔掉）
- 不要把水表 `000722` 读成 `72.2`
- 不要把电表上下两行 `1505 / 2777` 读成 `1505.2777`
- 不要默认 YKE 电表都是两位小数；必须以屏幕真实小数点为准
- 不要把生活水表和消防水表混填；看不出是哪一块水表时，按上传顺序假设并降低置信度
