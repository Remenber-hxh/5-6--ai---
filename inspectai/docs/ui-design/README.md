# 智巡前端设计图包

本目录用于沉淀系统首页与核心子页面的高保真前端设计图，重点覆盖移动端巡检流程与后台管理端。

## 文件

- `index.html`：完整设计图看板，可直接用浏览器打开。
- `ui-design.css`：设计图样式。
- `ui-design-board.png`：导出的完整设计图截图。
- `backend-admin-complete.html`：参考后台管理端样式制作的完整后台高保真图。
- `backend-admin-complete.css`：完整后台图样式。
- `backend-admin-complete.png`：完整后台图导出截图。

## 页面范围

- 移动端：系统首页、拍照识别、AI 识别中、字段确认、日报预览、资产台账。
- 后台端：后台首页、资产台账、资产详情、巡检记录、异常复核、修改审批。

## 设计原则

- 用户端突出“拍照即采集、识别后确认、确认后入账”的闭环。
- 后台端突出“资产台账、异常复核、修改审批、巡检追溯”的管理闭环。
- 页面内容使用当前项目真实字段口径：能耗抄表、综合巡检、消防泵房、弱电机房、Z1-Z4 能耗表、生活水表、消防水表等。
- 设计图只做前端视觉与信息架构参考，不替代接口实现。
