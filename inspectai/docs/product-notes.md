# 智巡 · 产品待解决问题与设计方向

> 记录于 2026-05-28。来源：产品负责人 + 领导提出的几个核心痛点。
> 这几个问题互相咬合，不是孤立功能。下方按问题列出「问题 / 为什么重要 / 建议 / 权衡」。

---

## 1. 后台只有异常记录，没有正常记录

**问题**：管理后台默认只展示异常/待复核记录，正常巡检看不到。

**为什么重要**：
- 「正常」本身是最重要的数据。出事故时，能证明「巡了、当时正常、有照片有时间戳」是**免责和尽职的关键证据**；只存异常等于把最有力的证据扔了。
- 「正常」是「异常」的基线 —— 没有正常读数，趋势对比、阈值告警都无从谈起（见 #3）。
- 领导要看的不只是「出了几个问题」，更是「巡检到底有没有在发生」—— **覆盖率**（今日应巡 X / 已巡 Y / 异常 Z）。

**建议**：每次巡检（正常/异常）都落一条记录；后台默认展示全部 + 顶部「正常 / 异常 / 待复核」筛选；正常记录可折叠聚合，但必须可查。主要是展示层调整，不是重构。

**权衡**：正常记录量大，需要聚合视图避免淹没异常。

## 2. 人工惰性 + 二次校正流于形式 + AI 不精准（最关键）

**问题**：设置了人工二次校正，但人不一定真看；AI 给的数据也不一定准。全量人工复核 = 一定退化成无脑点「确认」。

**为什么重要**：这是「人在环」机制的根本风险。流于形式的复核 = 没有复核，还给了虚假的安全感。

**建议**（重新设计复核结构，而不是「逼人认真」）：
- **风险分级路由**：AI 高置信 + 低后果字段直接过；只有低置信或高影响（压力/温度等安全相关）才强制人工。把稀缺注意力集中到要紧处。
- **主动确认，不是被动点钮**：关键字段改成让人重新敲一遍数值 / 回答定向问题（「读数是 0.6 还是 0.8MPa？」）。摩擦力按风险给。
- **把证据摆到眼前**：字段旁直接放 AI 截出的表计放大图，人对着图核对（2 秒一瞥），而不是盲信 AI 数字 —— 同时承认 AI 不一定准，人核的是图。
- **抽检 + 留痕反惰性**：记录谁确认、停留多久；主管随机抽 X% 复核；某人抽检老出错就标记。**真问责才治惰性**，这是管理机制不是技术。
- **趋势兜底**（接 #3）：本次读数偏离历史 2σ，即使人点了「正常」也自动升级复核。机器在背后接住人的惰性。

**权衡**：摩擦 vs 效率。全复核没人认真，全自动出错漏网；价值就在「按风险分流」这门手艺。

## 3. 设备报告 + 时间维度对比（demo 最该重点做）

**问题**：内部缺少以设备为中心的报告，缺少同一报告随时间的对比。

**为什么重要**：慢性劣化是单次巡检永远看不出、趋势一眼就看出的。这是 AI 巡检相对人工的**真正增量价值**，从「记录」升级到「预测性维护」。也是 demo 最能打动评委的故事。

**建议**：
- **设备档案页**（以资产为中心）：某台设备的全部历史巡检 —— 读数时间线、状态变迁、异常、照片，一页看完。
- **趋势对比**：关键读数（温度/压力/振动/电流）按时间画曲线，标出漂移；本次 vs 历史均值/基线告警。
- 反哺 #2：趋势就是对人和 AI 的双重交叉校验。

**权衡**：需要积累一定历史数据才有趋势；demo 可用预置/模拟数据先把能力讲清。

---

## 4. 感知类项目（听 / 闻 / 体感）怎么设

**问题**：照片拍不到的感官项，AI 无法判断。

**建议**：别让 AI 假装能判断，改成「AI 提示 + 结构化人工录入」。
- **结构化单选**代替自由文本：声音 [正常/异响-摩擦/异响-撞击/啸叫]、气味 [无/焦糊/油味]、体感 [常温/温热/烫手]。点一下即可，且变成可分析、可对比的数据。
- **听**可采集：录 3–5 秒音频存证（未来可上模型）；嗅/体感只能靠人 → 结构化选项 + 异常时必填原因/补照。
- 模板引擎支持「AI 读图」以外的字段类型：**人工感官单选 / 录音 / 手填**，并作为对应设备的强制清单项防漏。

**权衡**：又回到惰性 —— 默认给「正常」，但选异常必须留证据，控制在 2–3 下点完。

## 5. 系统暗病

**问题**：系统还有很多隐性问题（暗病），怎么系统化解决。

**建议**（让暗病现形，而不是盲解）：
- **建一份「已知问题」清单**，按（概率 × 影响）排序 —— 从隐形变成可管理的列表。
- **加埋点/指标**：重拍率、AI 失败率、人工转写率、审批超时率、错误率，做「系统健康看板」—— 暗病变成数字就不再是暗病。
- **真实环境试跑**：比赛前让真巡检员对真设备走一遍，暗病在真实使用下暴露最快。

**待补**：具体暗病清单（逐条列出后再排优先级）。

## 优先级建议（比赛 / demo 导向）

1. **#3 设备趋势对比** —— 最出彩、最能讲「AI 增量价值」
2. **#1 正常记录 + 覆盖率** —— 工作量小，补基本面
3. **#2 证据摆眼前 + 风险分级** —— 把复核闭环讲圆
4. **#4 结构化感官** —— 体现「全场景巡检」完整度
5. **#5 暗病** —— 持续进行，需先列具体清单
