## 一句话

角色管「能做什么」，数据范围管「能看多少」，项目管「看哪一片」。三件事分开存，
合起来决定一个人打开页面看到什么。**混在一起是这套系统之前没法接项目组的根因。**

## 三步走

| 步骤 | 内容 | 状态 |
|---|---|---|
| 1 | 数据范围显式化：`users.data_scope`，行为不变 | ✅ 已完成 |
| 2 | 项目实体化：`projects` 表 + `user_projects` 多对多 + 查询过滤 + 存量迁移 | 待做（3–5 天） |
| 3 | 组织架构：项目挂到组织树，总部按树聚合 | 视客户需求，可缓 |

## 第 1 步做了什么（已上线代码）

- 迁移 **013 `user_data_scope`**：`users` 加一列 `data_scope`，默认空。
- `data_scope.go`：`effectiveDataScope(r)` / `canSeeAllData(r)`。
- 替换了**七处**原本用 `hasSupervisorAccess(r)` 表达数据范围的判断：
  巡检记录列表、资产快照、修改申请列表、某资产的申请、角标计数、离线照片、待办任务。
- 后台「用户与权限」页可以配置，列表可见，变更进操作审计。

### 三条不能动的规则

1. **空值必须按角色推导。** 空回落到固定档会出事：回落 `self` → 存量管理者
   看起来"数据全没了"；回落 `all` → 存量巡检员越权看全租户。
2. **非法值也回落角色，绝不放行看全部。** 少看是体验问题，多看是事故。
3. **`data_scope` 不影响动作权限。** 配了 `self` 的主管照样能审批 —— 他只是看得少。

### 取值

| 值 | 含义 | 现状 |
|---|---|---|
| 空 | 按角色推导（管理角色看全部，其余看自己的） | 默认，存量全是这个 |
| `all` | 本租户全部 | 生效 |
| `self` | 只看自己提交的 | 生效 |
| `project` | 本项目全部（含组内其他人） | 生效 |
| `project_self` | 本项目台账 + 仅本人记录 | 生效 |

## 第 2 步做了什么

前提（做之前确认过的）：一个人属于多个项目；**总部要能看到所有项目的设备台账**
（领导明确要求，对应数据范围「全部数据」，不受项目限制）。

- 迁移 **014**：`projects` + `user_projects`，并从 `assets` / `records` 已有的
  项目名**回填**（不回填的话升级后列表是空的，管理员会手建一个同名的，
  差一个字就和台账脱钩）。本机 MySQL 实测回填出两个项目，设备数 23/12 与台账一致。
- 后台：项目卡片（设备数为 0 会标黄 = 项目名和台账对不上）+ 用户弹窗多选项目。
- 过滤：`dataVisibility` 一个结构体表达"能看到什么"，各查询按它裁。

### 项目范围到底限了哪些页面

| 数据 | 项目范围下的表现 | 为什么 |
|---|---|---|
| 设备台账 | 只看本项目 | 有项目字段，能精确过滤 |
| 巡检记录 | 只看本项目（`project_self` 再收紧到本人） | 同上，且**在 SQL 里过滤** |
| 设备详情/历史/报告 | 越界一律 404 | 路由层收口，见下 |
| AI 问答 | 同样受限，越界设备答"不存在" | 页面挡住但一问 AI 就说出来 = 后门 |
| 修改申请 / 工程待办 / 角标 / 离线照片 | **退回"只看自己的"** | 这些表没有项目字段（待办按责任人姓名归属） |

最后一行是**故意选严的一档**：严了他当场就会来问，松了没人发现而数据已经过界。

### 三个不能改的实现细节

1. **单台设备的检查在路由层收口**（`handleAssetRoutes`）。详情、历史、报告、
   封面、申请、状态事件各有 handler，逐个加检查必然漏一个，漏掉的那个就是
   一条不报错的越权通道。
2. **越界返回 404 不是 403。** 403 等于确认"这台设备存在，只是不给你看"，
   拿编号一台台试就能把别的项目的台账摸出来。AI 那边同理，越界和不存在给同一句话。
3. **记录过滤必须在 SQL 里。** 先取最新 100 条再在内存里筛，等于"从最新 100 条里
   挑本项目的"，冷清一点的项目直接筛空，页面还不报错。有测试钉着这条。

### fail closed

配了「本项目」却一个项目都没分到 → **什么都看不到**。放行的话这个配置就是
一句空话：管理员以为限住了，实际他看得见全部，且毫无迹象。后台在选这一档时
会强制要求至少选一个项目。
