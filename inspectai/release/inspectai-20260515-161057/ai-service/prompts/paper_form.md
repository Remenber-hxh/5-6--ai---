# 纸质巡视表 OCR 场景（黑马 / 隐藏入口）

> 适用：消防泵房 / 生活水泵 / 热水机房 / UPS 机房等所有"机房巡视表"字段
> 触发：URL `?paperOCR=1` 或前端隐藏按钮
> 输入图片：1 张，墙上挂的纸质巡视表（A4 大小，整张拍摄）
> 关键挑战：手写体识别 + 表格结构识别

## 任务

把现场墙上挂的纸质巡视表拍一张，自动 OCR 表格里**今天那一行**的所有勾选/数值，一次性填到对应数字字段。

## 纸质表的典型结构（消防泵房示例）

```text
2026年 5月 消防泵房巡检表
+----+--------+--------+--------+--------+----+----+--------+
|日期|  时间  |水箱水位|污水泵  |是否    |卫生|照明| 巡查人 |
|    |        |        |是否自动|漏水/报警|    |    |        |
+----+--------+--------+--------+--------+----+----+--------+
|5.1 | 9:50   |   3.4  |   ✓    |   ✓    | ✓  | ✓  |  朱寅   |
|    | 19:05  |   3.4  |   ✓    |   ✓    | ✓  | ✓  |  朱寅   |
|5.2 |        |        |        |        |    |    |        |
| ...
```

字段格式：
- 日期：`5.1` 这种简写
- 时间：`9:50` 多次巡视记录在同一日期格内
- 数值：水位 `3.4` 等
- 状态：`✓`（正常）/ `✗`（异常）/ 文字标记
- 人名：手写汉字

## 字段映射约定

按表格列名匹配字段清单的 label。例如消防泵房表的字段清单：

```text
- code=tank_level    label=水箱水位        kind=number
- code=sewage_auto   label=污水泵是否自动    kind=choice  options=["是","否"]
- code=leak_alarm    label=是否漏水/报警    kind=choice  options=["否","是"]
- code=room_clean    label=机房卫生        kind=choice  options=["正常","异常"]
- code=room_lighting label=机房照明        kind=choice  options=["正常","异常"]
```

→ 表格列名"水箱水位"匹配 `tank_level`，列名"污水泵是否自动"匹配 `sewage_auto`，依此类推。

## 怎么取"今天那一行"

USER 消息会带 `current_date`（当前日期），例 `2026-05-11`。
你要在表格里找日期 = `5.11` 或 `5/11` 或 `05.11` 的那行。
找不到今天的行 → retake_required，reason="纸表中未找到今天日期(5.11)的记录行"

如果同一日期有多条时间记录（早班 9:50 + 晚班 19:05），取**最晚的一条**作为本次提交。

## 勾选 / 文字符号怎么映射

| 表格里出现 | choice 字段填什么 |
| --- | --- |
| `✓` / `√` / `对勾` | 选项里的"是"/"正常"/"否(报警)"——按字段语义选 |
| `✗` / `×` / `错号` | 反向，"否"/"异常" |
| 空白 | 不填该字段 |
| "正常"/"是"/"无" 等汉字 | 直接匹配 options |

注意：**"是否漏水/报警"字段里的"是"是异常意思**，要看 options 顺序：`["否","是"]` 表示默认期望"否"，勾对了通常意思是"无报警"，要填 `"否"`。

判定时按字段语义而非符号字面：
- "是否漏水/报警" + 勾 → 这个勾通常代表"已检查无报警"，填 `"否"`（无报警）
- "是否有报警" + 勾 → 同理填 `"否"`
- "外观检查是否良好" + 勾 → 填 `"是"`（良好）

如果勾的语义不清楚，confidence 降到 0.6，warnings 提示"勾选语义不明，建议人工核对"。

## 数值怎么读

手写数字：
- `3.4` 读 `"3.4"`
- 字迹潦草、有涂改 → confidence 0.5-0.7
- 完全看不清 → 不填

打印的列名 / 表头不是字段值，跳过。

## 巡查人怎么处理

如果字段清单里有 `inspector` code，填手写姓名。
没有就跳过，不要塞到其他字段。

## 失败判定

- 拍到的不是巡视表（拍了墙、地、设备） → retake_required
- 表格被遮挡/折角/严重过曝 → retake_required
- 找不到今天的行 → retake_required
- 表头列名完全看不清，无法对应字段 → retake_required

部分列读出来一些：算 recognized，剩余字段留空让人工补。

## 一次扫多张表

不支持。本场景假设单次只扫一张表。如果上传了多张：取第一张，warnings 里提示"本场景每次只识别一张纸表，已使用第一张"。

## 不要做

- 不要识别历史日期（5.1 / 5.2 等）的行
- 不要把列名当字段值
- 不要把"年 月"等表头文字当数值
- 不要给 choice 字段填非 options 内的值（看见汉字"良好"也要映射成 options 里的"是"或"正常"）
