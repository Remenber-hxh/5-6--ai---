# JADEAST 智巡后台管理端

独立后台管理端口：`18081`  
业务 API：`18080`  
AI 服务：`19100`

## 本地启动

先启动原有后端与 AI：

```powershell
.\scripts\start-local.ps1
```

再启动后台管理端：

```powershell
.\scripts\start-admin.ps1
```

访问：

```text
http://127.0.0.1:18081
```

## 当前功能

- 驾驶舱：资产总数、异常资产、巡检记录、待审批申请。
- 资产台账：查看资产长期状态，主管可直接修改资产名称、状态和管理摘要。
- 巡检记录：查看一次性巡检记录、图片、识别字段和 AI 总结。
- 异常复核：处理巡检员提交的修改申请，通过后落到后端资产/记录数据。
- 系统健康：展示管理端、Go API、AI 服务、数据库/存储的端分离链路。

## 端分离说明

移动端用户窗口继续使用 `frontend`，由 Go 后端在 `18080` 提供。

后台管理端使用 `admin-frontend`，由独立静态服务在 `18081` 提供。它不直接写文件、不绕过后端，所有数据读写都通过 `18080` 的 API 完成。
